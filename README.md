# BM Home · Halını Tasarla (test sürümü)

Müşterinin desen seçip desenin alanlarına renk verdiği halı tasarım sayfasının deneme sürümü.
bmhome.com.tr'de henüz yayında değildir; desen ve renk listesi örnektir.

- `index.html`: sayfa
- `veri/katalog.json`: renk ve desen listesi
- `veri/doku/`: her rengin düz halı fotoğrafı
- `veri/desen/`: desen alan maskeleri ve gölge katmanları
